# تصاویر بخش کمک در صفحهٔ اصلی

سه عکس کوچک برای کارت‌های «راه‌های همراهی». تا وقتی این فایل‌ها ساخته نشده‌اند، صفحه از عکس‌های آرشیو موجود استفاده می‌کند.

هر تصویر را دقیقاً با همین نام در این مسیر بگذارید:

`apps/site/public/images/landing/`

نسبت تصویر ۴:۳، افقی، حدود ۱۶۰۰×۱۲۰۰. بدون نوشته، لوگو، واترمارک، یا چهرهٔ قابل شناسایی از یک شخص واقعی. نور گرم، عکاسی واقعی، آرام و محترمانه. نه پوستر تبلیغاتی، نه لبخند استوک شرکتی.
